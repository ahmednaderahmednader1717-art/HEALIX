# HEALIX

**HEALIX** is a smart, offline-first Flutter application designed for comprehensive nutrition tracking and diet management. Built as a graduation project, it empowers users to seamlessly monitor their daily macronutrient intake (Calories, Protein, Carbs, Fats) through a modern, responsive interface.

### Key Features:
- **AI-Powered Meal Scanning:** Leverages the Google Gemini Vision API to instantly identify meals from device photos, estimate nutritional values, and automatically suggest flexible unit serving sizes (grams, ml, pieces).
- **Offline-First Logging:** Tracks meals and daily progress using robust local caching, allowing users to log standard database foods and AI scans completely offline.
- **Advanced Diet Filtering:** Provides backend integration to search and filter foods by various diets (Vegan, Vegetarian, Pescatarian) and food categories.
- **Dynamic Progress Tracking:** Visualizes nutritional goals through donut charts, visual calendars, historical thumbnail galleries, and weight progression milestones.
